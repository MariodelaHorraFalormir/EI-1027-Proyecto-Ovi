Nota importante para la corrección

Los siguientes casos son ejemplos base que pueden probarse para revisar las funcionalidades principales de la aplicación.

Casos base de prueba

Estos casos no son los únicos posibles. Sirven como recorrido recomendado para comprobar las funcionalidades principales de la aplicación.

1

Crear un usuario

Comprobar el registro de una nueva persona en el sistema.

Usuario
  • Ir a la página de registro.
  • Crear un nuevo usuario con sus datos personales.
  • Comprobar que el usuario puede iniciar sesión.
  • Acceder a su perfil para verificar que los datos se han guardado correctamente.
2

Obtener y gestionar roles

Comprobar la asignación de roles a una persona registrada.

Admin OVI
Usuario recomendado
admin1@ovi.es
Contraseña
admin123
  • Entrar como administrador.
  • Ir a Gestión OVI > Personas registradas.
  • Abrir el detalle de una persona.
  • Pulsar Gestionar roles.
  • Asignar un rol disponible, por ejemplo Ovi User o PAP/PATI.
  • Comprobar que el usuario obtiene los permisos correspondientes.
3

Aprobar solicitudes

Comprobar el flujo administrativo de revisión.

Admin OVI
Usuario recomendado
admin1@ovi.es
Contraseña
admin123
  • Iniciar sesión como administrador.
  • Acceder a Gestión OVI > Todas las solicitudes.
  • Abrir una solicitud pendiente.
  • Revisar sus datos.
  • Aprobar la solicitud.
  • Comprobar que el estado cambia a Aprobada.
4

Solicitar revisión de una solicitud rechazada

Comprobar que el usuario puede pedir una segunda revisión.

Flujo usuario
Usuario recomendado
joel.user@ovi.es
Contraseña
user123
  • Iniciar sesión como usuario.
  • Entrar en Mis solicitudes.
  • Abrir una solicitud rechazada.
  • Pulsar la opción de Solicitar revisión.
  • Comprobar que se genera una nueva petición o que cambia el estado correspondiente.
5

Editar los datos de un perfil

Comprobar la modificación de datos personales.

Usuario
Usuario recomendado
joel.user@ovi.es
Contraseña
user123
  • Iniciar sesión como usuario.
  • Entrar en Mi perfil.
  • Pulsar la opción de editar datos.
  • Modificar algún campo del perfil.
  • Guardar los cambios.
  • Comprobar que los nuevos datos aparecen correctamente.
6

Realizar una PA Request

Comprobar que un OVI User puede solicitar asistencia personal.

PA Request
  • Iniciar sesión con un usuario que tenga rol Ovi User.
  • Ir a Servicios.
  • Seleccionar la opción para solicitar asistencia personal.
  • Completar el formulario de PA Request.
  • Enviar la solicitud.
  • Comprobar que aparece en Mis solicitudes o Mis procesos.
7

Aprobar una PA Request

Comprobar el flujo de aprobación de una solicitud de asistencia personal.

Admin OVI
Usuario recomendado
admin1@ovi.es
Contraseña
admin123
  • Iniciar sesión como administrador.
  • Entrar en Gestión OVI > Todas las solicitudes.
  • Abrir una solicitud de tipo PA Request.
  • Revisar los datos introducidos por el usuario.
  • Aprobar la solicitud.
  • Comprobar que el proceso queda disponible para su seguimiento.
8

Hablar por el chat

Comprobar la comunicación asociada a un proceso.

Chat
  • Iniciar sesión con un usuario que tenga un proceso asociado.
  • Entrar en Mis procesos.
  • Abrir el detalle de un proceso.
  • Acceder al chat asociado.
  • Enviar un mensaje.
  • Comprobar que el mensaje aparece correctamente en la conversación.

Recordatorio final

Estos son algunos casos base que esperamos que faciliten la corrección. Recuerde que puede recrearlos con otros usuarios si lo considera necesario, actualizando la contraseña del usuario para poder acceder con él y asignándole permisos de administrador cuando necesite probar funciones de gestión.
