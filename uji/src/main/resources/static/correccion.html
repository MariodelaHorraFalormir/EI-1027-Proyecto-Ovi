Nota importante para la corrección

Los casos de prueba se reinician en cada ejecución para que puedan ser probados desde cero. Se recomienda no dejar ninguna historia de usuario a medias: si se empieza una prueba, conviene completarla antes de pasar a la siguiente para mantener el estado de la aplicación coherente.

Historias de usuario recomendadas

Cada tarjeta indica con qué usuario iniciar sesión y qué tareas realizar.

1

Acceso como administrador

Comprobar el acceso al panel de gestión OVI.

Admin OVI
Usuario
admin1@ovi.es
Contraseña
admin123
  • Iniciar sesión como administrador.
  • Comprobar que aparece el menú Gestión OVI.
  • Entrar en Personas registradas.
  • Revisar el listado de personas.
  • Abrir el detalle de una persona registrada.
2

Gestión rápida de roles

Probar la creación y eliminación de roles desde el detalle de persona.

Admin OVI
Usuario
admin1@ovi.es
Contraseña
admin123
  • Entrar como administrador.
  • Ir a Gestión OVI > Personas registradas.
  • Abrir el detalle de una persona.
  • Pulsar Gestionar roles.
  • Crear rápidamente un rol disponible.
  • Borrar un rol asignado cuando el sistema lo permita.
  • Volver al detalle y comprobar que los botones de rol se actualizan.
3

Revisión de solicitudes

Comprobar el flujo administrativo de solicitudes.

Admin OVI
Usuario
admin1@ovi.es
Contraseña
admin123
  • Iniciar sesión como administrador.
  • Acceder a Gestión OVI > Todas las solicitudes.
  • Revisar solicitudes de OVI User, PAP/PATI o PA Request.
  • Abrir una solicitud y revisar sus detalles.
  • Resolver una solicitud cuando proceda.
  • Comprobar que el estado cambia correctamente.
4
